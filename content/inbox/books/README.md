# Buch-Highlights

Lege hier pro Buch eine Markdown-Datei ab (z.B. `never-split-the-difference.md`).

Format pro Highlight, getrennt durch eine Leerzeile:

    > Das Zitat, wörtlich aus dem Buch.
    > Darf über mehrere Zeilen gehen.

    Quelle: Titel, Autor, Kapitel
    Topic: verhandlung

`Topic` ist optional: `verhandlung`, `strategie` oder `startup` (Default `strategie`).
Der nächste tägliche Lauf macht daraus Karten. Das Zitat ist der wörtliche Auszug.
